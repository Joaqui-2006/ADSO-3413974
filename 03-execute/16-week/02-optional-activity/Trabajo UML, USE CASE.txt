Proyecto : Sistema de Registro de Asistencia para Instructores del Sena

-Problema: La toma de asistencia en sofia plus es muy lenta

-Solución: Sistema con más agilidad para la toma de asistencia

-Objetivo: Facilitar el registro de asistencias e inasistencias de los aprendices mediante una aplicación sencilla que permita al instructor realizar el proceso de forma rápida y organizada, reduciendo el tiempo empleado en comparación con el procedimiento actual.

#Requerimientos funcionales:

- RF-01 : El sistema debe listar automáticamente los aprendices de la ficha seleccionada.
- RF-02: El sistema debe permitir modificar una asistencia antes de cerrar el registro.
- RF-03: El sistema debe permitir consultar asistencias registradas anteriormente.
- RF-04: El sistema debe permitir buscar un aprendiz por nombre o documento.
- RF-05: El sistema debe mostrar alertas cuando un aprendiz supere el límite de inasistencias permitido.
- RF-06: El sistema debe permitir consultar el historial de asistencia de un aprendiz.
